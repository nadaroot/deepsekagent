# NonRoot — Autonomous AI Agent (OpenCode 1:1)

**NonRoot** — это автономный ИИ-агент разработки на базе моделей DeepSeek (V3 и R1 Reasoning), созданный для локального исполнения задач программирования, системного администрирования и исследования кодовых баз.

Интерфейс приложения выполнен в строгой тёмной стилистике **OpenCode 1 в 1**, без лишних элементов и AI-slop.

---

## 🚀 Основные возможности

- **Автономный ReAct цикл**: Агент самостоятельно планирует действия, вызывает инструменты, анализирует результаты и итерирует до достижения цели.
- **Инструменты (Tools)**:
  - `run_command` — выполнение команд в терминале.
  - `read_file`, `write_file`, `edit_file` — точечная работа с файлами и кодом.
  - `list_dir`, `grep_search` — исследование структуры и поиск по проекту.
  - `web_fetch` — получение содержимого веб-страниц и документации.
- **Субагенты (Subagents)**: Возможность порождать параллельных субагентов для независимых исследований и подзадач с отображением их статуса в сайдбаре.
- **DeepSeek V3 & R1 Thinking**: Поддержка моделей `deepseek-chat`, `deepseek-reasoner` (с выводом блоков мышления `<think>`) и кастомных эндпоинтов.
- **Мультимодальность**: Загрузка скриншотов и фото с автоматической обработкой в чате.
- **Режим Auto-Accept**: Переключатель `⚡ Auto-Accept: ON/OFF` для мгновенного автономного подтверждения действий без ручных диалогов.
- **Кроссплатформенность**: Готовые сборки и ярлыки для Windows, macOS и Linux.

## 📦 Быстрый старт

### Вариант 1: Запуск через Python
```bash
# Клонировать репозиторий
git clone https://github.com/nadaroot/nonroot.git
cd nonroot

# Запустить NonRoot
python nonroot.py
```
При запуске агент автоматически откроет интерфейс в браузере (или в app-режиме): `http://127.0.0.1:8765`.

### Вариант 2: Запуск по команде `nonroot`
- **Windows**: Запустите `scripts/setup_windows.bat` (создаст ярлык на рабочем столе и добавит команду `nonroot` в PATH).
- **macOS**: Запустите `scripts/setup_macos.sh` (добавит команду `nonroot` в `/usr/local/bin` и создаст бандл `NonRoot.app` в `~/Applications`).
- **Linux**: Запустите `scripts/setup_linux.sh` (создаст команду `nonroot` в `~/.local/bin` и `.desktop` ярлык).

---

## 🛠️ Сборка в единый исполняемый файл

```bash
python build_standalone.py
```
Результат будет сохранен в папке `dist/` (`NonRoot.exe` на Windows или `NonRoot` на macOS/Linux).
